# 🔎 TRACE — Digital Investigation Platform

TRACE is an interactive digital investigation platform developed as a digital investigation case experience. It allows users to examine evidence, investigate suspects, identify contradictions, connect clues, and reach a final deduction.
## Demo Video

https://drive.google.com/file/d/1WGZgevyOZ9xnn6SQUDBHjoS4TltOkMri/view
## Features

- Interactive digital investigation
- Evidence collection and unlocking
- Encrypted transmission / Caesar cipher challenge
- Multiple evidence items
- Suspect dossiers
- Interactive suspect interrogation
- Contradiction detection
- Evidence connection system
- Final accusation
- Investigation report generation
- Downloadable case report

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite
